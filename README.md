  ## 学习原则

  1. 先自己思考，再查看答案。
  2. 代码尽量自己手写，不直接复制完整答案。
  3. 遇到错误先阅读报错信息。
  4. 使用 AI 时优先询问原因和提示，而不是直接生成完整程序。
  5. 每个知识点都通过实际代码进行验证。
  6. 每天学习结束后更新学习笔记。
  7. 每个学习日完成 Git commit 并同步到 GitHub。
  8. 阶段学习完成后独立完成小项目进行综合练习。
